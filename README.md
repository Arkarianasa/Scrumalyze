<h2>Tool for agile process evaluation, especially SCRUM</h2>
<p>
    This tool is designed for the effective implementation of a methodology for evaluating agile processes, with an emphasis on SCRUM.
</p>

<h3>Development:</h3>
<p><a href="https://visualstudio.microsoft.com/cs/vs/community/">Visual Studio 2022 Community Edition</a></p>
<a href="https://visualstudio.microsoft.com/cs/vs/community/">.NET 8.0</a>

<h3>Configuration</h3>
<p>
    Add your own <code>appsettings.json</code> file, containing connection strings and other configuration details. This file should not be committed to version control.
</p>

<h3>Installation:</h3>
<p>You need to install following NuGet packages via the NuGet Package Manager in Visual Studio:</p>
<ul>
  <li>Microsoft.EntityFrameworkCore.SqlServer</li>
  <li>Microsoft.EntityFrameworkCore.Tools</li>
  <li>Microsoft.Extensions.Configuration</li>
  <li>Microsoft.Extensions.Configuration.FileExtensions</li>
  <li>Microsoft.Extensions.Configuration.Json</li>
</ul>
